# 기여 방법

새 자료를 제안할 때 다음 정보를 포함해 Issue 또는 Pull Request를 생성합니다.

- 공식 제목과 URL
- 논문/뉴스/white paper/code/dataset 중 유형
- DOI 또는 arXiv ID
- Attack, Propagation, Defense, Evaluation, Threat Model 중 역할
- self-evolution lifecycle 단계
- 3–5문장 자체 요약
- 확인된 한계와 공개 artifact
- 저자 주장인지 독립 재현인지 여부

기사나 논문 원문을 복사하지 말고 공식 링크와 자체 요약을 사용합니다.
